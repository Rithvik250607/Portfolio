# Rithvik P R - Portfolio

> A clean, modern, and classy developer portfolio with subtle Iron Man & Arc Reactor accents, interactive particle physics, smooth scroll animations, and Dark/Light theme switching.

---

## 🚀 How to Run

### Option 1: Direct Browser Launch
Simply double-click `index.html` to open it in Chrome, Edge, Firefox, or Safari.

### Option 2: Local Server
In your terminal from this directory:
```powershell
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

---

## 🛠️ Customization Guide

### 1. Profile Picture
- Your portrait (`profile.jpg`) is now integrated into the `assets/` folder and framed within the Arc Reactor halo. If you ever want to update it, replace `assets/profile.jpg` with a new image.

### 2. Resume Section
- Currently displays "My resume will be available here soon." When you're ready to share your resume, you can link your PDF directly in `index.html`.

### 3. Adding Projects Later
- In `index.html`, locate the `<section id="projects">` section when you're ready to add completed projects with descriptions, tech stacks, and links.
